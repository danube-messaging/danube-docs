## Try it in 30 seconds

```bash
# 1. Start a local node on 127.0.0.1:6650
danube up standalone

# 2. Create a durable topic by saying what it is for
danube topic create /default/events --intent event_stream

# 3. Start a reader, then send from another terminal
danube consume /default/events
danube produce /default/events -m 'hello'
```

That's the whole setup. No config files, no ZooKeeper, no separate schema registry.

## Why Danube

<CardGrid>
	<Card title="One binary, zero YAML" icon="rocket">
		`danube` is the broker, the CLI, the MCP server and the console backend. Grow from one node to a Raft cluster with flags, not config files.
	</Card>
	<Card title="Say what a topic is for" icon="star">
		Pick an intent (`realtime`, `event_stream`, `task_queue`, `audit_log`) and Danube sets delivery, durability, retries and dead-letter queues for you.
	</Card>
	<Card title="Built for AI agents" icon="puzzle">
		Task queues with leases and checkpoints, request/reply, audit logs, topic branching for replay, and an MCP server so agents can run the cluster.
	</Card>
	<Card title="Cheap durability" icon="approve-check">
		Fast local WAL, with segments tiered to S3, GCS, Azure or a shared filesystem. Built-in schema registry on the same port.
	</Card>
</CardGrid>
