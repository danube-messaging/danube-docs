Run Danube on your own machine with a single binary. No Docker, no config files, no external services.

```bash
danube up standalone
```

## Install the binary

Download `danube` for your platform from the [releases page](https://github.com/danube-messaging/danube/releases) and put it on your `PATH`. The same binary is the server, the CLI and the MCP server.

```bash
danube version
```

Run `danube` on its own at any time for an overview of every command. It never starts a server.

## Send your first messages

<Steps>
1. **Start a standalone node.**

   ```bash title="Terminal 1"
   danube up standalone
   ```

   The node listens on `127.0.0.1:6650` and stores its data in `./danube-data`, next to where you ran the command. The first start prints a warning about that default directory, which is expected.

2. **Create a topic by describing what it is for.**

   ```bash title="Terminal 2"
   danube topic create /default/orders --intent event_stream
   ```

3. **Start a consumer.**

   ```bash title="Terminal 2"
   danube consume /default/orders -s my-sub
   ```

4. **Produce a few messages.** `event_stream` topics are reliable, and the producer follows the topic's strategy.

   ```bash title="Terminal 3"
   danube produce /default/orders -m "hello danube" --count 5
   ```

   The consumer prints each message as it arrives.
</Steps>

Every CLI command talks to `http://127.0.0.1:6650` by default. Pass `--endpoint` to reach another node.

## Keep data in a fixed place

Stop the node with Ctrl-C. Starting it again from the same directory resumes the same node with all its topics and messages.

To avoid surprises when you change directories, give the node an explicit path:

```bash
danube up standalone --data-dir ~/danube-data
```

## Run a three-node cluster on one machine

Every node needs its own data directory, client port and Raft port. All three list the same seed nodes.

```bash title="Terminal 1"
danube up cluster --data-dir ./data/node1 \
  --listen 127.0.0.1:6650 --raft-port 7650 \
  --seed-nodes 127.0.0.1:7650,127.0.0.1:7651,127.0.0.1:7652
```

```bash title="Terminal 2"
danube up cluster --data-dir ./data/node2 \
  --listen 127.0.0.1:6651 --raft-port 7651 \
  --seed-nodes 127.0.0.1:7650,127.0.0.1:7651,127.0.0.1:7652
```

```bash title="Terminal 3"
danube up cluster --data-dir ./data/node3 \
  --listen 127.0.0.1:6652 --raft-port 7652 \
  --seed-nodes 127.0.0.1:7650,127.0.0.1:7651,127.0.0.1:7652
```

Check that the nodes found each other:

```bash
danube cluster status
danube broker list
```

<Aside type="tip">
  Prefer to start with one node and add the others later? Follow [Grow from one to three nodes](/getting-started/broker-modes/#grow-from-one-to-three-nodes).
</Aside>

## Clean up

Stop each node with Ctrl-C, then remove the data for a fresh start:

```bash
rm -rf ./danube-data ./data
```
