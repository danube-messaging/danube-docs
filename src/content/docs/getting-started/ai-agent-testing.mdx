The [Danube Agent Skills](https://github.com/danube-messaging/danube-agent-skills) repository lets you test Danube using AI coding assistants. Describe what you want to test in plain English, and the AI sets up infrastructure, runs the test, and reports results, no manual configuration needed.

## How It Works

Open the repository in an AI-powered IDE (Claude Code, Cursor, Windsurf, VS Code + Copilot, or any agent that reads `SKILL.md` files), type a prompt, and the AI handles everything:

- Downloads binaries from GitHub Releases
- Generates broker configs from templates
- Starts brokers, forms clusters, creates namespaces
- Installs client libraries as needed
- Runs the test scenario step by step
- Reports pass/fail results

Each test run creates an isolated directory with all configs, logs, and data. Nothing is shared between runs.

## Quick Start

<Steps>
1. **Clone the repository**

   ```bash title="Terminal"
   git clone https://github.com/danube-messaging/danube-agent-skills.git
   cd danube-agent-skills
   ```

2. **Open in your AI IDE**

   Open the `danube-agent-skills` folder in your preferred AI-powered editor or terminal.

3. **Tell the AI what to test**

   Type a prompt like:

   > *"I want to test reliable delivery with NACK redelivery"*

   The AI reads the skill files, asks a few clarifying questions (which aspect, which setup method), and then executes the scenario.
</Steps>

:::tip
You don't need to download Danube binaries, write configs, or install client libraries manually. The setup scripts handle everything automatically based on the scenario you choose.
:::

## Setup Methods

The AI will ask which setup method to use. Pick whichever fits your environment:

| Method | Best For |
|--------|---------|
| **Local Binary** | Quickest start, downloads pre-built binaries, no dependencies beyond `curl` |
| **Local Source** | Developers working on the Danube codebase, builds from source with `cargo` |
| **Docker Compose** | Container-based setups, supports special infrastructure (MinIO, Valkey) |
| **Kubernetes** | Production-like testing, deploys via Helm chart |
